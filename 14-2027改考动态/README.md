# 14-2027 改考动态（最新一条线）

本目录是**滚动更新的「2027 最新改考 / 新增专业」台面**，专门收最新的 408、22408、11408 变动信息。它和 `06-院校数据库` 的分工是：

| | 本目录 `14-2027改考动态` | `06-院校数据库` |
|---|---|---|
| 定位 | 最新变动的**对外汇总面**（人读 + 机读各一份） | 统一库**正本**与派生页面 |
| 收录 | 只收**已用官方原文逐字复核过**的 2027 条目 | 全字段结构化数据（含历史年份） |
| 写入方式 | 直接改本目录两个文件 | 只能通过 `contributions/<校名>.json` 投稿，由脚本再生 |
| 提交范围 | **单独提交这一个目录即可** | 属另一类提交（要进主库/上 Pages 时才做） |

## 目录内容

- [`2027改考台账.md`](./2027改考台账.md) —— 人读台账，一校一段：院校｜学院｜专业代码｜2026→2027 变化｜四门科目代码｜归类｜来源与复核状态，末尾是「未取到 / 待核」清单。
- [`latest_2027.json`](./latest_2027.json) —— 机读版（`schema: change2027-v1`），与台账逐条对应，每条都带 `source{title,url,tier,date}` 和 `verified` 布尔值；`pending[]` 里是明确**没有**下结论的院校与原因。

## 收录口径（硬规则）

1. **只认官方 T1**：研究生院 / 学院官网 / 章程与目录的 PDF·xlsx·docx 附件原文。第三方（呱呱研选、研呱呱、eol.cn、知乎、小红书、任何机构号）一律不作源——前两家有实锤数据造假记录。
2. **每条必须有原文逐字摘录 + 直链 + 落款或发布日期**，不能只写结论。
3. **区分四种情形**，不许混为一谈：`新开专业` / `延续` / `缩量` / `仅接推免`。「目录里出现了某代码」不等于「新扩」。
4. **按学院+专业代码拆口径**，禁止整校套：同校常出现 085404 走 408、085410 走自命题（四川轻化工、湖北汽车工业、合肥大学都是这种）。
5. **公共课必须写实**：`22408`=204 英语二 + 302 数学二 + 408；`11408`=201 + 301 + 408；英一/数一与英二/数二混排的（如 201+302）单独写清楚，不归类为上面两者。
6. **未取到就写未取到**，附失败路径（维护中 / 反爬 / 需登录 / 接口缺陷），不推测、不搬别校。

## 以后怎么提交（只动这个目录）

```bash
cd <仓库根目录>
# 1) 改完 2027改考台账.md 与 latest_2027.json
python 09-生成脚本/validate_contributions.py   # 投稿通道自检
python 09-生成脚本/publish_check.py            # 门禁 C1–C17 必须全 PASS
git add 14-2027改考动态
git commit -m "docs(2027动态): 新增 N 条改考复核，M 条待核"   # 标题中性，不写校名+专业代码
git push origin main
```

两点注意：

- **提交标题要保持中性**。提交列表是公开可读的，标题里不要出现「某校+某专业代码+人数」这类指向性信息。
- 本目录里**只用绝对 https 链接指向官方原文**；不要放指向尚未提交文件的相对链接，否则推上去就是 GitHub 上的死链（门禁 C11 只在本地能过，骗不过线上）。
