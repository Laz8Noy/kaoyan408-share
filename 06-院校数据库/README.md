## 二、读取路径（AI 建议）

1. 先读 `data/meta.json` 得到全部学校清单；`conflicts_registry.json` 是**必须优先查看**的警告清单（涉及 22408 口径的科目/线差异）。
2. 目标学校查 `data/schools/<编号>-<校名>.json`：
   - `units[]` = 该校的"学院 × 085410 相关招生单位"行（含 2026 复试线/计划/一志愿与调剂/热度/N诺列）；
   - `crossRefs[]` = 无法归入具体学院的跨学院参考行（例：成信工用 085411 近似 085410 考情）；
   - `kaoqingDetail2026[]` = 官方细节行/深档补充（成信工含逐批次）；
   - `updates2027[]` / `tutors[]` / `wangdaoLinks{}` / `sources[]`；
   - **`conflicts[]` 里的条目：字段为"待核/警告/参考"时，做决策前必须复核官方原文，不能直接采信单一 claim。**
3. 每个 `unit` 的 `subjectClass` 是汇总口径的**分类标签**：`22408`=英二数二408；`混合`=同校不同学院/方向科目不一致；`11408`=英一数一408（与 22408 不符）；`非408`/`待确认`/`推测408` 同理。科目细项见 `nnSubjects` 或对应学校的深档。
4. 2027 改考信息在 `updates2027[]` 与 `conflicts_registry.json`；**研招网 2027 硕士目录约 2026-09 中旬发布，发布后请先核对再引用。**

## 三、AI 使用约定

- 数据语言：键名英文小写驼峰、值中文；空值统一为 `null`；"未公布/无数据"用 `null` 或原文 `—` 保留在字符串里。
- 数值字段类型：能转数的已转成 number（线/计划/人数/均分），不能确定的保持字符串。
- 引用格式建议：`（来源：文件名/Sheet，2026-09-03 汇总）`；冲突条目引用时带 `status`。
- 本库是"整理资料"，不等于官方；凡用于报名决策，最后一律以**当年官方招生简章/研招网目录/学院公示**为准。

### 数据清洗

- **剔除零值占位行**：Dai408 源数据中有 87 条记录同时满足「复试 0 人 / 录取 0 人 / 分数全 0」，这些 `0` 并非真实分数（实为当年无数据）。若直接保留，会把「最低分 0」排到榜首并污染均值统计。生成脚本已将这类行的**分数与人数置空**，仅保留专业目录信息（学院/专业/代码/科目/单科线）。
- **数值格式**：页面渲染只剥除小数点后的尾零，保证 `400` 这类整数不被截断为 `4`（已用 4000 个单元格回归校验，零不一致）。

### 口径提醒（重要）

- 「录取最低/最高/平均分」各来源均为**初试总分**口径，但统计总体可能是**拟录取名单**或**复试池**（CodeBrick 数据以 `distPopulation` 标注），跨源比较前请先确认口径。
- 「复试线」存在**国家线 / 院校线 / 院系线 / 专业线**四种口径，本页分区展示、不混用。
- **报录比官方普遍不公布**，为空属正常；复录比 = 复试人数 ÷ 录取人数。
- 小样本（recordCount < 30）的分位数波动大，仅供参考。
- 全部内容为 AI 辅助整理自公开渠道，**未逐一官方核实，报考决策务必以当年官方招生简章与研招网目录为准**。
