18 个线上 HTML 全量探活（均 200）；逐页量首屏传输量与外部依赖；用浏览器实际点开索引页 /

先说结论里"好"的部分，不是客套：数据侧的诚实度高于同类站点——`src:["区域榜","三源核对"]`
的来源分级、详情页「待补字段工单」、「原始值含复合描述（已拆主值，原文保留在 `*_note`）」、
`docs/口径.md` 作为唯一权威口径 + 门禁 C9 对账，这套东西大部分信息站根本不做。
观测站首屏 56KB、零外部依赖；名词罗盘虽是 React 构建，首屏 1.55MB、字体按 unicode-range
懒加载 21 个，实际很克制。
