# 408 公开资源导航（正版友好）

本仓库**不收录**王道教材 PDF、湖科大课件 PPT 等受版权保护的文件。  
下面这些都是 GitHub 上已经公开的笔记 / 导图 / 工具，请直接去原仓库 star、clone。

> 复习仍建议：正版王道书 + 网课 + 下面的开源笔记对照。

## 推荐组合

| 用途 | 仓库 | 说明 |
|---|---|---|
| 日常文字笔记 | [amatureemoprince/Awesome-408](https://github.com/amatureemoprince/Awesome-408) | 四科 markdown 笔记、数据结构 C 代码、小林 coding 专栏 |
| 分章笔记 + 经验 | [LYuYang61/408](https://github.com/LYuYang61/408) | 手写/整理笔记、考研经验；**不要**把别人仓库里的王道 PDF 再传到网上 |
| 四科思维导图 | [Ryan2ky/408xmind](https://github.com/Ryan2ky/408xmind) | xmind 格式，作者 408 考 126/131，需 [XMind](https://xmind.cn/) 打开 |
| 课件融合成 Obsidian 笔记 | [F0T0ne/408-courseware-notes](https://github.com/F0T0ne/408-courseware-notes) | Codex Skill，把你**自己拥有的**课件整理成两级目录笔记 |
| 另一套导图 | [naplatte/CS-Postgraduate-Entrance-Examination-408-Database](https://github.com/naplatte/CS-Postgraduate-Entrance-Examination-408-Database) | 按大纲铺开的导图 |
| 计网通俗向 | 小林 coding 公开专栏（见 Awesome-408 内链接） | 适合计组/计网入门 |

## 建议使用顺序

1. **第一轮**：王道书逐章 + Awesome-408 文字笔记  
2. **补原理**：计组看小林专栏；计网可配湖科大**公开课视频**（B 站），课件请用课程官方渠道  
3. **搭框架**：Ryan2ky/408xmind 一科一张图  
4. **刷题**：王道习题 + 真题；算法题用 Awesome-408 里的 C 代码练手写  
5. **复试机试**：按目标校官网复试细则自备（本仓库已不再收录机试清单），提前练 C / C++ 上机
