# 目录分类说明

本仓库只收录：**择校数据、考情整理、复习导航、可公开的网页工具**。  
个人健康数据、豆包聊天记录、API Key、1GB+ 的第三方笔记镜像均未入库。

| 目录 | 你要解决的问题 | 先看哪个文件 |
|---|---|---|
| `01-择校与规划` | 我怎么排 18 周、冲稳保怎么定 | `085410_22408_择校与规划_20260820.md` |
| `02-院校数据` | 全国双非 / 408 大盘历史表 | 带日期的最新 html/xlsx |
| `03-川渝408` | 川渝院校对比、图表 | `川渝408.html` 或 `图表修复/` 里优化版 |
| `04-终极版择校` | **当前主成果**：筛选、热度、推荐器、三源核对 | `查看指引_终极版.md` |
| `05-院校专档` | 某一所学校挖深 | 暂无内容（空目录不入库），欢迎提交单校专档 PR |
| `06-院校数据库` | 给脚本 / AI 读的 JSON | 该目录 `README.md` |
| `07-考情资料` | 王道链接、N诺提取、录取名单原文 | 各子目录 README |
| `08-推荐器网页` | 独立推荐器 HTML | `kaoyan-recommender-full.html`（全量版，单文件） |
| `09-生成脚本` | 改表后重新导出 | 11 个生成/补丁脚本，详见该目录 README |
| `10-录取分数统计` | 96 所学校 2024-2026 分数分布（408 单科分位数） | 该目录 `README.md` |
| `11-408专业课交互课件` | 排序算法可视化、408 观测站（四科 14 个交互实验） | 该目录 `README.md`；观测站入口 `408观测站/index.html` |
| `12-408名词罗盘` | 四科核心名词的轮盘式图鉴 + 名词手册/思维导图 PDF 在线读 | `index.html`（站点即入口）；源码与重建方法见 `project/` 与该目录 `README.md` |
| `docs/` | 408 公开链接、贡献与口径 | `408公开资源导航.md` |

## 版本怎么选（避免被旧文件带偏）

- 择校主表：优先 **20260826 终极版**（在 `04-终极版择校`），不要停在 08-12 / 08-17 旧稿  
- 规划文档：优先 **20260820** 的 md/xlsx/html  
- 数据库：`06-院校数据库` 已按 2026-09-03 复核过一批冲突（如南信大改考代码、天工大分数线）

> `02-院校数据` 的 20260820、`04-终极版择校` 的 20260824 属**历史存档**（仅供对照"数据是怎么长出来的"，数值早于 09-03 复核修正，勿当最新结论用）。最老的 20260813 一代 4 件已于 2026-09-13 删除，需要时可在 Git 历史找回。
