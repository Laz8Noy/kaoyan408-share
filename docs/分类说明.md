## 数据维护与过程记录

- [09-生成脚本](../09-生成脚本/README.md)：现役生成器、补丁与历史脚本。运行前先看状态；部分旧脚本缺失输入或会覆盖人工修正。
- [CONTRIBUTING.md](../CONTRIBUTING.md)：纠错、结构化投稿格式、来源要求与修改约束。
- [deliverables/](../deliverables/)：按批次保存的补录说明、来源证据、变更快照、日志与一次性工具。它们用于追溯，不能代替当前数据正本；其中脚本也不能直接当作通用构建命令运行。
- [docs/](./)：数据口径、来源规则、资源导航与历史评审。带日期的评审记录代表当时状态。

## 如何选择版本

1. 查当前院校信息，先用[院校索引](../06-院校数据库/索引.html)或[数据浏览器](../06-院校数据库/院校数据浏览器.html)，再追到来源。
2. 使用择校专题时，以 04 目录的 20260826 版作为该工具的后续维护版本；02 的 20260820、04 的 20260824 保留作历史对照。
3. 文件名日期不等于每个字段的核验日期。即使文件较新，也要按学校、学院、专业、年份与来源判断。
4. HTML、JSON 与表格可能是同一数据的不同输出，不要把每份输出都当成独立正本。具体依赖与再生方式见对应目录和[生成脚本说明](../09-生成脚本/README.md)。

本轮文档整理保留现有目录和文件路径，避免影响网页互链与构建脚本。
