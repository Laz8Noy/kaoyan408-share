# 05-院校专档

> 本目录为**单校深挖专档**，存放针对某一所学校的详细分析：复试细则、导师方向、历年报录比趋势、上岸经验帖汇总等。

## 当前状态

**21 所重点校深度专档**（10 所完整版 + 11 所精简版，清单见 [`_index.json`](_index.json)，总表见 `专档索引.xlsx`，数据底稿在 `_数据底稿/`）+ **其余 156 所轻量速览**（[`其余院校速览.md`](其余院校速览.md)，由 `09-生成脚本/build_school_profiles.py --light` 生成）。欢迎继续贡献 🙌

如果你对某所学校有深入了解，欢迎按 [`CONTRIBUTING.md`](../CONTRIBUTING.md) 提交 PR，格式建议：

```
05-院校专档/
├── 学校名称/          # 如 成都信息工程大学
│   ├── README.md     # 整体分析
│   ├── 复试细则.md    # 复试形式、机试/面试内容
│   └── 数据/          # 历年分数线、录取人数等
```

## 为什么需要这个目录

- `04-终极版择校` 是**横向对比**（所有学校一张表）
- `05-院校专档` 是**纵向深挖**（一所学校多角度分析）

两者互补，帮助你在冲稳保框架下确定目标后，深入评估单校的性价比和上岸难度。
