## 🔬 408 观测站：`408观测站/index.html`（2026-09-14）

多文件交互实验站（入口是文件夹里的 `index.html`，本地双击或在线打开均可，**无外部网络依赖**）。把 408 四科里**最抽象**的知识点做成「拨参数 → 逐帧推演」的实验，共 **14 个**：

| 学科 | 实验 |
|---|---|
| 组成原理（4） | 虚拟地址→物理地址（TLB/缺页三种情形）、Cache 三种映射命中率对比、流水线数据相关与前递、中断 vs 异常的控制流 |
| 数据结构（3） | 六种内部排序逐步对比、Dijkstra 最短路（可调边权/起点）、AVL 四种旋转（LL/RR/LR/RL） |
| 操作系统（4） | 进程调度 FCFS/SJF/RR（甘特图逐拍）、缺页置换 FIFO/LRU/OPT、生产者-消费者三信号量、银行家算法安全序列 |
| 计算机网络（3） | TCP 滑动窗口与累计确认/快重传、拥塞控制锯齿（经典 Reno 口径）、CIDR 最长前缀匹配 |

- 每个实验可 **播放 / 单步 / 回退 / 拖时间轴**，切换参数立即从第 0 帧重算；每帧配「此刻发生了什么 + 抓住这个关键 + 从动画回到考题」
- 左侧导航记录探索进度（只存本机浏览器）；快捷键：空格播放、←/→ 单步、R 重置
- 教学简化模型，各实验边界在页内注明（如窗口实验不含拥塞控制、OPT 仅作理论基准），不替代教材与真题

在线地址：<https://laz8noy.github.io/kaoyan408-share/11-408%E4%B8%93%E4%B8%9A%E8%AF%BE%E4%BA%A4%E4%BA%92%E8%AF%BE%E4%BB%B6/408%E8%A7%82%E6%B5%8B%E7%AB%99/index.html>
