## 必须先看的避坑（截至 2026-09 整理）

这些是整理过程中反复踩过的坑，**报名前再核一次**：

- **分学院**：同一所大学的 085410 可能有的考 22408，有的考 11408 / 自命题。例如北交大不同学院科目不同；中石油华东不同学院不同；深大整理时按 11408 口径处理过。
- **改考**：南信大 2027 不再按 408 理解（数据库里已改为自命题代码，以简章为准）；上海电力、长春工业等 085410 也可能不是 408。
- **线低 ≠ 稳**：看复试最低 / 平均 / 录取人数，不要只看国家线。云南大学 2026 线大幅上涨且上机占比高。
- **11408 混进表**：N诺等机构表常把英一数一 408 和英二数二 408 放在一起。三源核对表里标了警告的行，不要当 22408 来报。

完整提醒仍以 `04-终极版择校` 的「改考动态」与 [`2027改考动态_20260820.md`](04-终极版择校/2027改考动态_20260820.md) 为准。
