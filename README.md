# 考研 408 公开资料库（kaoyan408-share）

> ⚠️ **声明：本仓库全部内容均由 AI 辅助整理，信息来源自网络公开渠道**（各校研究生院/学院官网、研招网、王道论坛、N诺考研、机构公开资料及网络讨论等），未经逐一官方核实，可能存在错漏。**仅供参考，报考务必以当年官方招生简章与专业目录为准。**

本库**以考 22408（政治 + 英语二 + 数学二 + 408）的院校为主力收集对象**——主要是 085410 电子信息 / 人工智能等专硕方向；同时也收录 11408（英语一 + 数学一 + 408，学硕）以及其他考 408 的院校数据与录取分数。面向 2027 考研（2026 年 12 月初试）的计算机相关同学。

本仓库把本地整理过的**择校表、考情、复试机试清单、推荐器网页、录取分数统计、408 交互学习工具**公开出来，并给出 408 复习的 **GitHub 导航**（不搬运商业教材）。

## 必须先看的避坑（截至 2026-09 整理）

这些是整理过程中反复踩过的坑，**报名前再核一次**：

- **分学院**：同一所大学的 085410 可能有的考 22408，有的考 11408 / 自命题。例如北交大不同学院科目不同；中石油华东不同学院不同；深大整理时按 11408 口径处理过。
- **改考**：南信大 2027 不再按 408 理解（数据库里已改为自命题代码，以简章为准）；上海电力、长春工业等 085410 也可能不是 408。
- **线低 ≠ 稳**：看复试最低 / 平均 / 录取人数，不要只看国家线。云南大学 2026 线大幅上涨且上机占比高。
- **11408 混进表**：N诺等机构表常把英一数一 408 和英二数二 408 放在一起。三源核对表里标了警告的行，不要当 22408 来报。

完整提醒仍以 `01-择校与规划` 主文档和终极版「改考动态」Sheet 为准。
