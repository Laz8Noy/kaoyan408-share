# 考研 408 公开资料库

整理计算机考研的院校信息、择校资料和 408 交互学习工具，支持在线查阅。

**在线访问：[laz8noy.github.io/kaoyan408-share](https://laz8noy.github.io/kaoyan408-share/)**

资料由 AI 辅助整理，来源包括高校官网、研招网及第三方公开资料，尚未逐条完成官方核验。历史数据主要围绕 **085410 · 22408** 收集，其他专业和科目组合覆盖不均。报考前请按招生年份、学院、专业和学习方式核对当年官方文件。

## 查院校与择校

| 想做什么 | 入口 | 使用说明 |
|---|---|---|
| 按学校、专业或招生单位代码搜索 | [院校索引](https://laz8noy.github.io/kaoyan408-share/06-院校数据库/索引.html) | 在线首页默认入口，可继续跳到数据浏览器或院校专档 |
| 查看分数、计划、科目和来源 | [院校数据浏览器](https://laz8noy.github.io/kaoyan408-share/06-院校数据库/院校数据浏览器.html) | 各字段的年份与统计范围可能不同，注意来源和备注 |
| 对比学校、参考冲稳保分档 | [择校专题](https://laz8noy.github.io/kaoyan408-share/04-终极版择校/全国408_085410双非热度版_终极版_20260826.html) · [独立推荐器](https://laz8noy.github.io/kaoyan408-share/08-推荐器网页/kaoyan-recommender-full.html) | 以历史 085410 资料为主，分档仅供初步筛选 |
| 深入了解目标校与导师 | [院校专档](05-院校专档/README.md) · [导师信息](01-导师与规划/085410_22408_导师信息_20260820.md) | 专档与导师资料保留整理时点，需再次核对 |
| 查看收集到的 2027 招生调整 | [改考动态](14-2027改考动态/README.md) | 与院校库分别维护；是否已同步入库，以目录说明为准 |

建议先用索引找学校，再查看数据来源和院校专档。比较分数时，要区分复试线与录取分、招生计划与实际录取人数、一志愿与调剂；同一专业在不同学院也可能采用不同考试科目。

库内不同页面的覆盖范围不同，数量不能直接互相替代，详见[数据口径](docs/口径.md)。当前院校库的更新说明见[数据库 README](06-院校数据库/README.md)。

## 下载与维护

- **找文件**：见[目录说明](docs/分类说明.md)，包含当前入口、历史资料与源码位置。
- **纠错或补数据**：见[贡献指南](CONTRIBUTING.md)，或提交 [Issue](https://github.com/Laz8Noy/kaoyan408-share/issues)。请附学校、学院、专业、年份和原始来源链接。
- **修改后检查**：见[生成脚本与发布流程](09-生成脚本/README.md)。部分历史生成器无法直接重跑，请先确认脚本状态。
- **判断来源与处理冲突**：见[数据源与冲突裁定](docs/数据源与冲突裁定.md)。
